Backup & Restore Data

Protect your patient clinic records and uploaded files safely.

Create Local Backup

Saves a complete copy of the database and uploaded images inside your Documents folder.

Email Backup Settings

Configure your Gmail account to automatically receive database backups by email.

📋 How to get a Gmail App Password:
Go to myaccount.google.com → Security → 2-Step Verification (enable it) → App Passwords → Select "Mail" → Copy the 16-character password and paste it below.

Send Backup by Email

Creates a fresh backup of the database and sends it as an attachment to your configured recipient email.

The backup file is attached to the email as a .backup.json file and can be restored later using the card below.

Restore from Email Backup

Upload a .backup.json file received by email to restore your complete database.

⚠️ Warning: This will replace your current database with the backup. Your existing data will be lost. A safety snapshot is automatically saved before restoring.
